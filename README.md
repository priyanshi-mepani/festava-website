# Festava Live Website 🎵

A responsive event website developed using HTML, CSS and JavaScript as part of my BTEC IT coursework.

## About the Project

Festava Live is a website designed to provide information about a live music and events festival.

The website includes different sections for visitors to explore the event, including information about the festival, schedule, speakers and registration.

## Features

- 🎵 Festival event information
- 📅 Event schedule
- 👥 Speaker information
- 📝 Registration section
- 📱 Responsive website design
- 🎨 Styled interface using CSS
- ⚡ Interactive elements using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript

## Local Server Deployment

The website was also tested and hosted locally using:

- VirtualBox
- Debian Linux
- Local web server
- Local hostname: `priyanshi-server.local`

The website was tested locally rather than being publicly hosted online.
